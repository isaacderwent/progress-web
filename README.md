# Progress on the web

The built web app of Progress, a personal strength-training log, served by
GitHub Pages at https://isaacderwent.github.io/progress-web/.

This repository holds the built files only. The source is kept privately,
and each version replaces everything here with one fresh commit, so nothing
here is edited by hand.

To use it on an iPhone, open the address in Safari, tap the share button,
then Add to Home Screen. Your workouts stay in that browser on that device,
and nothing is sent anywhere.

The fonts are Geist and Geist Mono, under the SIL Open Font License, and the
icons are Phosphor Icons, under the MIT licence. Both licences ship with the
app and are listed on its About page.
